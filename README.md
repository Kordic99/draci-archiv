# Liškaplikace – přesměrování

Tento repozitář udržuje původní adresu webu. Aplikace a její zdroje jsou na [Kordic99/liskaplikace](https://github.com/Kordic99/liskaplikace); online knihovna je na [kordic99.github.io/liskaplikace](https://kordic99.github.io/liskaplikace/).

Stránka přenáší parametry odkazu i fragment přihlášení pouze na pevně určenou novou adresu ve stejné doméně. Neobsahuje knihy, zápisky ani přístupové údaje.
